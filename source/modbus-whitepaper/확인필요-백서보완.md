# 백서 보완이 필요한 항목

랜딩페이지 쪽 문제는 이번에 모두 고쳤습니다. 아래는 **제품 사실 확인이 필요해 임의로 쓸 수 없는 항목**들이라
본문에 넣지 않고 남겨 둡니다. 값을 확인해 주시면 해당 절에 바로 반영하겠습니다.

정합성 검사는 통과했습니다 — 슬롯 주소 계산식(40101 + 16 × (N−1))은 256슬롯까지 전부 일치하고,
그림 번호 22개 모두 정의·참조·파일이 맞물려 있으며 누락된 이미지는 없습니다.

---

## 1. KC 인증과 국내 주파수 — 우선순위 1

현재 백서에는 `900MHz FHSS, 868 / 433MHz 대역 지원`이라고만 되어 있습니다.
국내 ISM 대역은 917~923.5MHz이고, 담당자나 사내 품질·안전 부서가 가장 먼저 확인하는 항목입니다.
이 정보가 없으면 기술 검토를 통과해도 결재 단계에서 멈춥니다.

확인해 주실 것

- 국내 판매 모델의 실제 동작 주파수 대역
- KC 적합성평가(적합인증 또는 적합등록) 취득 여부와 인증번호
- 미국향 902~928MHz 모델과 국내 모델이 별도 품번인지 여부

넣을 위치: 11장 사양표 하단에 "국내 인증" 행 추가, 3장 게이트웨이 선택 기준에 한 줄 각주.

## 2. 영하 온도 표현 방식 — 우선순위 2

5장에서 온도를 `÷100`으로만 설명합니다. 영하일 때 레지스터가 어떤 값으로 나오는지가 빠져 있어,
냉동창고·옥외 판넬·동절기 기계실에서 상위 시스템이 65000 같은 값을 읽는 사고가 납니다.

확인해 주실 것

- 온도 레지스터가 16bit **부호 있는 정수(2의 보수)** 로 표현되는지
- 예를 들어 −5.5℃일 때 Modbus Poll에서 실제로 표시되는 값

확인되면 5장에 계산 예시 한 줄과, 10장 증상별 점검표에 "겨울에만 온도가 650℃로 나온다" 항목을 추가하겠습니다.

## 3. 통신 두절 시 측정값 레지스터의 거동

4장에 동작 상태(+4)가 0이 되고 Data Age(+3)가 증가한다는 설명은 있지만,
그때 **Data 1~8이 마지막 값을 유지하는지, 0으로 바뀌는지**가 없습니다. 알람 로직을 짜는 쪽에서는 이 한 줄이 결정적입니다.

같이 확인이 필요한 것: 미사용 채널의 "N/A"가 실제로 어떤 숫자로 읽히는지(0인지 다른 값인지).

## 4. 게이트웨이 자체 레지스터 표

그림 4-2 설명에 "게이트웨이 자체 정보(상단)"라고 언급만 되어 있고 표는 본문에 없습니다.
상위 시스템에서 **게이트웨이 자체의 생존 여부(워치독)** 를 감시하려면 이 영역이 필요합니다.
지금 구성으로는 개별 센서 장애는 잡히지만 게이트웨이가 통째로 죽은 경우를 못 잡습니다.

필요한 것: 게이트웨이 정보 영역의 주소·항목 정의(제품 문서 해당 페이지 캡처면 충분합니다).

## 5. 폴링 설계 기준

"센서 전송 주기보다 짧게 폴링해도 갱신되지 않는다"까지는 있는데, 구현자가 필요한 숫자가 없습니다.

- 권장 폴링 주기
- 한 요청으로 읽을 수 있는 최대 레지스터 수 (Modbus 표준은 125 → 센서 7대분)
- 게이트웨이가 허용하는 동시 Modbus 마스터 접속 수
- 여러 슬롯을 한 번에 묶어 읽을 때의 권장 방법

## 6. 진동 센서 채널 정의

8장 적용 시나리오에서 펌프·모터 진동이 첫 번째 사례인데, 5장에는 진동 계열 채널 표가 없고
"해당 센서의 정의 문서를 기준으로"로 넘어갑니다. 진동을 보고 백서를 받은 사람이 원하는 표가 백서 안에 없는 상태입니다.

필요한 것: G-Force Max/Average 모델 한 종의 Data 1~8 매핑표.

## 7. 배터리 예상 수명

2V 이하 교체 기준은 있는데 몇 년 쓰는지가 없습니다. 전송 주기별(1분/5분/15분) 예상 수명이 있으면
유지보수 담당자가 순회 계획을 세울 수 있습니다.

---

## 넣으면 좋은 것 (사실 확인은 불필요, 판단만 필요)

- **폐쇄망 구성 한 페이지** — Modbus TCP는 인증이 없는 프로토콜이라 IT·보안 부서 승인이 실제 병목입니다.
  "Default Server Disable 시 외부로 나가는 트래픽 없음 + 내부 502 포트만 개방" 구성도 한 장이면
  담당자가 그대로 보안팀에 제출할 수 있습니다. 9장 체크리스트에 항목만 있고 본문 설명이 없습니다.
- **구성 예시 3종(최소·표준·확장)** — 품목 리스트가 있으면 담당자가 사내 품의를 쓸 수 있습니다.
  지금은 문의해야만 구성을 알 수 있는 구조입니다.
- **`1,200ft+` 에 `약 366m` 병기** — 국내 문서에서 피트만 쓰면 거리 감이 오지 않습니다.

## 공개 전 한 번 더 확인

백서 화면 캡처 22컷에는 캡처 당시의 실제 IP·센서 ID·측정값이 그대로 들어 있습니다.
광고로 외부에 배포하는 자료이므로, 공개해도 되는 정보인지 확인해 주십시오.
(랜딩페이지의 안내 문구는 "표의 값은 예시, 캡처는 실제 화면"으로 이번에 정리했습니다.)

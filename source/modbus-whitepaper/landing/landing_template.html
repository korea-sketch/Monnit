왜 미뤄졌는가

필요성은 알았지만 배선 때문에 미뤄둔 지점들

설비 데이터를 더 보고 싶다는 요구는 늘 있습니다. 막히는 지점은 대부분 센서가 아니라 배선과 상위 시스템 교체 비용입니다.

배선 비용과 공기

계측점 하나에 공사 한 건

배관·트레이·전원까지 따라붙고, 라인을 세워야 하는 구간은 결국 포기하게 됩니다. 무선센서는 게이트웨이 1대분 배선으로 끝납니다.

상위 시스템 교체 부담

화면이 둘로 나뉘면 안 본다

별도 모니터링 시스템을 도입하면 운전원은 결국 기존 화면만 봅니다. Modbus로 붙이면 쓰던 화면·알람·이력을 그대로 씁니다.

계측 사각지대

데이터가 비어 있는 구간

베어링, 물탱크 하부, 옥외 판넬, 창고. 비가시 환경에서도 1,200ft 이상 전송되므로 계측점으로 편입할 수 있습니다.

기술지원

백서대로 했는데도 값이 안 올라온다면

대부분은 아래 다섯 가지 중 하나입니다. 먼저 확인해 보시고, 그래도 해결되지 않으면 오른쪽 양식을 채워 korea@monnit.com 으로 보내 주십시오.

  1. Read Only 문구가 보이는가 — 보인다면 Unlock 모델이 아니거나 iMonnit에서 Modbus TCP가 꺼진 상태입니다.
  2. Default Server가 Disable인가 — Modbus 전용 운용 시 반드시 Disable. 연동 실패 원인 1위입니다.
  3. Status 탭에서 Modbus TCP가 On인가 — 게이트웨이 첫 화면에서 바로 확인됩니다.
  4. PC와 게이트웨이가 같은 네트워크인가 — 공유기 DHCP 목록에서 두 기기의 IP 대역을 봅니다.
  5. 센서 등록 후 Reform Now를 눌렀는가 — 누르지 않으면 값이 올라오지 않는 경우가 있습니다.

함께 보내주시면 회신이 빨라지는 화면 캡처 세 장 — ① Status 탭 전체, ② Default Server 설정 화면, ③ Modbus Poll의 읽기 설정 창과 값 화면(상단 오류 문구까지 보이게). 이 세 장이면 대부분 캡처만으로 원인이 잡힙니다.

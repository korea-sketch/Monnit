HVAC 모니터링

환경 모니터링 · 적용 센서: DP · TEMP

공조 시스템의 효율·필터 상태·차압을 실시간 추적.

온도·습도·누수·공기질 등 실내외 환경의 모든 변수를 통합 추적.

한눈에 보기

  • 주요 고객: 시설 운영팀 — 상업 빌딩·캠퍼스
  • 에너지 절감: 15–25% — 공조 운영비 절감
  • ROI 회수: <18개월 — 표준 빌딩 기준

01 · 고객 프로필

상업 빌딩 운영팀, 캠퍼스 시설관리, 의료기관, 데이터센터 등 대규모 HVAC 시스템을 운영하는 조직.

HVAC는 평균 상업 빌딩 에너지의 40%를 차지하며, 부적절한 운영은 곧바로 비용 증가로 이어집니다. 그러나 대부분의 시설은 BMS의 평균 데이터에만 의존하고 있어 세부 비효율을 잡아내지 못합니다.

필터 막힘, 덕트 누설, 펌프 부하 이상 등은 BMS만으로는 잘 보이지 않지만, 누적되면 막대한 에너지 낭비가 됩니다.

02 · 현재의 문제점

BMS만으로는 필터 상태·덕트 누설·국부적 차압 문제를 진단하기 어렵습니다.

  • 필터 막힘 사후 대응 — 정해진 교체 주기로만 관리해 막혀도 모르고 운영합니다.
  • 구역별 차압 모니터링 부재 — Zone별 정밀 차압이 없어 균형 손실이 누적됩니다.
  • 펌프·팬 부하 변화 미감지 — 전류 이상이 정비 시점을 알려주지만, 측정 자체가 없습니다.
  • HVAC가 에너지 비용의 40% — 비효율 누적이 곧 운영비 증가로 직결됩니다.

03 · Monnit 솔루션

기존 BMS를 대체하지 않고 보완합니다. ALTA 센서를 필터 전·후, 덕트, 펌프 패널 등 진단 포인트에 배치합니다.

Differential Pressure Sensor가 필터 차압을 추적해 정확한 교체 시점을 알려주고, Pipe Temperature Sensor가 냉·온수 배관 효율을 진단합니다. Current Sensor는 팬·펌프의 부하 변화를 감지해 정비 시점을 예측합니다.

ALTA Edge Gateway는 BACnet 통합 옵션을 제공해 기존 BMS와 자연스럽게 데이터를 교환합니다.

구성 센서: ALTA Differential Pressure · ALTA Pipe Temperature · ALTA Current · ALTA Edge Gateway

04 · 제안 단계

단일 빌딩 파일럿으로 절감 효과를 검증한 후 캠퍼스 전체로 확장합니다.

  • PHASE 1 기준 빌딩 선정 (1주) — 에너지 효율 진단 가능한 대표 빌딩 선정.
  • PHASE 2 센서 배치 (1주) — 필터·덕트·펌프 등 진단 포인트 12–20개 배치.
  • PHASE 3 3개월 데이터 분석 (3개월) — 이전 BMS 데이터와 비교해 비효율 진단.
  • PHASE 4 캠퍼스 확장 (2–4개월) — 검증된 구성으로 다른 빌딩 일괄 배포.

05 · 예상 ROI

표준 상업 빌딩 기준 18개월 내 ROI 회수, 이후 연 15–25% HVAC 운영비 절감이 지속됩니다.

  • 15–25% — HVAC 운영비 절감
  • 30%↓ — 필터 교체 비용 감축
  • <18개월 — 평균 ROI 회수 기간

도입 전: BMS 평균 데이터만 보유. 필터 교체는 시간 기반. 펌프 이상은 고장 후 인지.

도입 후: 필터 차압 정밀 추적. 데이터 기반 교체 주기. 펌프·팬 부하 패턴으로 정비 시점 예측.

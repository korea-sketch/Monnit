자주 묻는 질문

도입 전 질문부터 사용 중 문제 해결까지 정리했습니다. 찾는 답이 없으면 사이트의 모니에게 물어보세요.

센서 무선 통신 거리는 얼마나 되나요?

ALTA 무선 센서는 비가시선 기준 벽 12장을 관통해 1,200ft 이상, ALTA XL 게이트웨이 사용 시 벽 18장 관통 2,000ft 이상까지 통신합니다. 안테나 방향과 설치 환경에 따라 최적 성능이 달라집니다.

센서 배터리는 얼마나 가나요?

사용 환경에 따라 다르지만, 단일 AA 배터리로 최대 10년 이상 사용 가능합니다. 데이터 전송 주기(하트비트), 통신 거리, 장애물 수가 수명에 영향을 줍니다. 배터리 잔량은 iMonnit에서 백분율로 확인할 수 있고, 설정 임계값 이하가 되면 알림을 받을 수 있습니다.

인터넷이 끊기면 데이터가 사라지나요?

아닙니다. 게이트웨이 연결이 끊겨도 센서가 자체적으로 최대 4,000건의 측정값을 저장하며, 연결이 복구되면 누락 없이 전송합니다. 게이트웨이 역시 내부 메모리에 다수의 메시지를 저장합니다.

데이터 보안은 어떻게 보장되나요?

Encrypt-RF® 기술로 256-bit ECDH 키 교환과 AES-128 암호화를 적용해 센서~게이트웨이 구간을 보안 터널로 보호합니다. 또한 패킷 변조 검증 루틴으로 위·변조 및 재전송 공격을 차단합니다.

알림은 어떤 방식으로 받나요?

사용자가 설정한 조건을 초과하면 iMonnit이 SMS 문자, 이메일, 전화로 즉시 알림을 보냅니다. 임계값과 수신자는 자유롭게 설정할 수 있습니다.

설치와 설정은 어렵지 않나요?

대부분의 ALTA 센서는 전원을 켜는 즉시 게이트웨이에 연결되는 플러그앤플레이 방식으로, 시스템 구성에 보통 15분이면 충분합니다. Monnit Korea가 현장 설치와 초기 설정을 지원합니다.

사용 중 문제 해결

알리미를 받았어요. 설치는 어떤 순서로 하나요?

[알리미 설치·시험] 센서 등록과 알림 설정은 모넷코리아가 미리 해서 보내드려요. 현장에서는 「게이트웨이 달기 → 센서 붙이고 선 연결 → 시험」만 하면 되고, 십자 드라이버 하나로 15분 정도면 끝나요. 확인 순서: 1) 상자 확인: 게이트웨이 1대, 센서(신청한 개수만큼), 전원 어댑터, 양면테이프·나사가 들어 있어요. 십자 드라이버 하나만 준비해 주세요. 2) 센서 뒷면 라벨에 「어디에 붙일지」가 적혀 있으니 먼저 읽어 보세요. 3) STEP 1 — 게이트웨이를 벽에 달고 전원을 꽂아, 불빛 3개가 모두 초록이 되는지 확인해요. 4) STEP 2·3 — 알리미 종류별로 센서를 붙이고 선을 단자에 연결해요 (화재·정전·경보는 담당자와 함께). 5) STEP 4 — 설치가 끝나면 「설치 완료 확인 요청」을 남겨 주세요. 담당자가 연결 상태를 확인하고, 센서마다 한 번씩 시험해 문자가 오면 끝이에요.

알리미 게이트웨이는 어디에 달고, 불빛은 어떻게 봐야 하나요?

[알리미 설치·시험] 게이트웨이는 신호를 모아 보내는 상자예요. 벽에 달고 전원을 꽂은 뒤, 불빛 3개가 모두 초록이 되면 준비 끝이에요(최대 5분). 확인 순서: 1) 안테나를 하늘을 향해 똑바로 세워 주세요. 2) 눈높이쯤 벽에 나사로 고정하고, 전원선을 가까운 콘센트에 꽂아 주세요. 3) 센서를 붙일 장소(화재수신기·분전반 등) 근처, 센서와 같은 층에 두면 돼요. 센서와는 3m 이상 떨어뜨려 주세요 — 너무 가까워도 연결이 불안정해요. 4) 켠 직후에는 여러 색으로 깜빡이다가 최대 5분 안에 3개 모두 초록이 돼요. 5) 5분이 지나도 빨간 불이 계속되면 창가 쪽으로 옮겨서 전원선을 뺐다가 다시 꽂아 보세요.

알리미 센서 선은 단자에 어떻게 연결하나요? (4종 공통)

[알리미 설치·시험] 단자는 전선 끝을 넣고 나사로 꽉 눌러 고정하는 금속 부분이에요. 보통 숫자가 적힌 칸이 줄지어 있어요. 아래 네 동작이면 끝나요. 확인 순서: 1) 작업 전에 담당자(소방·전기·설비)에게 「지금 연결해도 되나요?」 먼저 물어봐 주세요. 2) 단자의 나사를 2~3바퀴 풀어 주세요. 3) 선 끝 금속 부분을 단자 안쪽 끝까지 넣어 주세요. 4) 나사를 꽉 조인 뒤, 선을 살짝 당겨서 빠지지 않으면 OK예요.

화재 알리미는 어디에 붙이고 어떻게 연결하나요?

[알리미 설치·시험] 화재 알리미는 화재수신기 안, 단자대 옆에 붙여요. 단자 연결은 반드시 소방안전관리자와 함께 해 주세요. 확인 순서: 1) 수신기 문을 열고 빈 공간에 센서를 양면테이프로 붙여요. 2) 센서 선을 위쪽 단자대까지 이어 줘요. 3) 소방안전관리자가 알려 주는 「화재 출력」 칸에 연결해요. 4) 아래쪽 전원 기판(전기가 들어오는 곳)은 만지지 마세요. 5) 문을 닫을 때 선이 끼지 않게 정리해 주세요.

물감지 알리미는 어디에 붙이나요? (기계실 바닥·집수정)

[알리미 설치·시험] 물이 제일 먼저 고이는 낮은 곳에 붙여요. 혼자서도 설치할 수 있어요. 핵심은 「감지선 끝만 바닥에, 본체는 벽에」예요. 확인 순서: 1) 배수구 옆, 배관·물탱크 밑처럼 물이 먼저 고이는 낮은 곳을 찾아요. 2) 본체는 물이 닿지 않게 벽에 30cm 이상 높이로 붙여요. 3) 기계실·화장실 바닥: 감지선 끝을 바닥에 딱 붙여 고정해요. 4) 집수정(지하 물 모이는 구덩이): 감지선 끝을 평소 물 높이보다 위, 「넘치기 직전」 높이에 고정해요.

정전 알리미는 차단기 어디에 연결하나요? (보조접점)

[알리미 설치·시험] 정전 알리미는 지킬 차단기 옆 「보조접점」에 선 2가닥을 연결해요. 보조접점은 차단기가 내려가면 함께 「딸깍」 바뀌는 신호용 부품이에요. 반드시 전기 담당자와 함께 해 주세요. 확인 순서: 1) 전기 담당자와 어떤 차단기를 지킬지 정해요 (메인, 냉동고·펌프 등). 2) 그 차단기의 보조접점에 센서 선 2가닥을 연결해요. 3) 보조접점에 다른 배선이 물려 있지 않은지 전기 담당자가 확인해 주세요. 4) 연결이 약하면(신호가 약하면) 센서를 분전반 바깥 옆면으로 옮겨 주세요.

경보 알리미는 설비 제어반 어디에 연결하나요? (ALARM 단자)

[알리미 설치·시험] 경보 알리미는 설비 제어반의 「ALARM(고장 출력)」 단자에만 연결해요. 설비 담당자와 함께 해 주세요. 확인 순서: 1) 설비 설명서에서 「ALARM」 또는 「고장 출력」 단자를 찾아요. 2) 그 단자 2칸에 센서 선을 연결해요. 3) 기계가 여러 대면 센서 라벨의 기계 이름과 맞는지 확인해요.

알리미 설치를 마쳤어요. 시험은 어떻게 하나요?

[알리미 설치·시험] 설치가 끝나면 「설치 완료 확인 요청」을 남겨 주세요. 담당자가 연결 상태를 확인한 뒤, 센서마다 한 번씩 시험해서 휴대폰에 문자가 오면 설치 끝이에요. 확인 순서: 1) 아래 「설치 끝났어요 — 연결 확인 요청하기」로 접수해 주세요 (현장명·알리미 종류를 적어 주시면 빨라요). 2) 물감지: 젖은 휴지를 감지선 끝에 대기 → 문자 확인. 닦아서 말리면 원래대로 돌아와요. 3) 화재: 소방안전관리자가 수신기 「동작시험」 (119 자동신고 장치가 있으면 먼저 끄기). 4) 정전: 전기 담당자가 차단기를 내렸다 올리기 → 정전 문자, 복구 문자. 5) 경보: 설비 담당자가 기계의 경보 시험 기능 실행.

센서를 등록했는데 반응이 없어요 (게이트웨이와 연결 안 됨)

[센서가 안 들어와요] 센서는 반드시 게이트웨이를 거쳐 iMonnit 으로 데이터를 보냅니다. 연결이 안 될 때는 대부분 「같은 네트워크 등록」과 「게이트웨이가 센서 목록을 새로 받는 순서」만 맞추면 해결됩니다. 확인 순서: 1) iMonnit 에서 센서와 게이트웨이가 「같은 네트워크」에 등록되어 있는지 확인해 주세요. 2) 네트워크 설정에서 「Holding Enabled(홀딩 네트워크)」가 체크되어 있다면 해제 후 Save 해 주세요. 체크되어 있으면 게이트웨이가 새 센서를 받지 않습니다. 3) 게이트웨이가 정상 체크인 중인지 확인해 주세요 (게이트웨이 LED 모두 녹색 / iMonnit 의 마지막 체크인 시각). 4) 센서 전원을 최소 60초간 꺼 주세요 (스위치가 없는 일반형은 배터리를 빼 주세요). 5) 그 사이 게이트웨이의 Utility(Reset) 버튼을 「짧게 한 번」 눌러 주세요. 게이트웨이가 iMonnit 에서 센서 목록을 새로 내려받습니다. 6) 센서 전원을 다시 켜고, 게이트웨이와 3~4m 떨어진 곳(너무 가깝지 않게)에 둔 채 1~2분 기다려 주세요. 처음 켜진 센서는 30초 간격으로 여러 번 연결을 시도합니다. 7) 그래도 안 되면 iMonnit 센서 Settings 하단의 「Default」 버튼으로 설정을 초기화한 뒤 4~6번을 한 번 더 해 주세요. 8) 센서에 물기·부식·배터리 누액 같은 흔적이 없는지 확인하고, 일반형(AA)은 새 배터리 또는 정상 작동 중인 센서의 배터리로 바꿔 시험해 주세요.

잘 되던 센서가 어느 순간부터 안 들어와요

[센서가 안 들어와요] 먼저 「센서 하나만」인지 「모든 센서」인지 구분해 주세요. 모든 센서가 멈췄다면 게이트웨이·인터넷 쪽, 하나만 멈췄다면 그 센서의 배터리·신호·주변 환경 쪽일 가능성이 큽니다. 확인 순서: 1) 모든 센서가 동시에 멈췄다면 → 게이트웨이 전원·LED·인터넷 연결부터 확인해 주세요 (아래 「게이트웨이 오프라인」 문서). 2) 센서 하나만 멈췄다면 → iMonnit 에서 그 센서의 마지막 체크인 시각, 직전 신호 강도·배터리 잔량을 확인해 주세요. 3) 게이트웨이의 Utility 버튼을 짧게 한 번 눌러 바로 체크인시켜 주세요. 4) 센서를 설치 위치에서 떼어 게이트웨이와 3~4m 거리에 두고, 전원을 60초 이상 껐다가 다시 켜 주세요. 5) 일반형(AA)은 새 배터리(또는 정상 센서의 배터리)로 바꿔 시험해 주세요. 6) 게이트웨이 근처에서는 잘 된다면 설치 위치의 장애물·거리·전자파 영향입니다. 위치를 조금 옮기거나 게이트웨이를 더 가까이 두면 해결됩니다.

센서·게이트웨이를 처음 설치할 때 올바른 순서가 궁금해요

[센서가 안 들어와요] 순서만 지키면 대부분 1~2분 안에 연결됩니다. 「iMonnit 등록 → 게이트웨이 켜기 → 센서 켜기 → 게이트웨이 버튼 한 번」이 기본입니다. 확인 순서: 1) iMonnit 에 게이트웨이를 먼저 등록합니다 (장치 ID + 보안코드 SC). 2) 같은 네트워크에 센서를 등록합니다. 3) 게이트웨이 전원을 켜고 정상 체크인(LED 모두 녹색)을 확인합니다. 4) 센서 전원을 켭니다 (일반형은 배터리 삽입, 산업용은 전원 버튼을 한 번 누름). 5) 게이트웨이 Utility 버튼을 짧게 한 번 누르거나 다음 체크인을 기다립니다. 6) 처음 연결된 센서는 30초 간격으로 여러 번(4~10회) 보고한 뒤 설정된 주기(기본 120분)로 돌아갑니다.

「홀딩 네트워크」가 뭔가요? 설정이 반영이 안 돼요

[센서가 안 들어와요] 「Fields waiting to be written…」은 오류가 아니라, 바꾼 설정이 게이트웨이에 대기 중이며 센서의 다음 정기 통신 때 전달된다는 뜻입니다. 오래 지속되면 아래 순서로 확인해 주세요. 확인 순서: 1) iMonnit → Settings → Networks → 해당 네트워크에서 「Holding Enabled」 체크를 해제하고 Save 합니다. 2) 센서의 다음 정기 통신(하트비트)까지 기다립니다. 하트비트가 120분이면 최대 2시간이 걸릴 수 있습니다. 3) 빨리 반영하려면 센서 전원을 60초 껐다 켜 주세요. 켜진 직후 30초 간격으로 여러 번 통신하면서 설정을 받습니다. 4) 산업용 센서는 전원 버튼을 짧게 눌러(Talk Now) 바로 통신시킬 수도 있습니다. 5) 그래도 안 되면 게이트웨이 Settings → Commands → 「Reform」을 실행한 뒤 센서 전원을 다시 껐다 켜 주세요.

「Not authorized to transfer」 라며 센서 등록이 안 돼요

[센서가 안 들어와요] 이 메시지는 해당 장치가 이미 다른 iMonnit 계정에 등록되어 있다는 보안 안내입니다. 기존 계정에서 장치를 삭제해야 새 계정에 등록할 수 있습니다. 확인 순서: 1) 라벨의 장치 ID 와 보안코드(SC, 영문 대문자)를 정확히 입력했는지 다시 확인해 주세요. 2) 혹시 우리 회사의 다른 계정·네트워크에 이미 등록되어 있지 않은지 확인해 주세요. 3) 이전 사용처가 있다면 그쪽 관리자에게 장치 삭제를 요청해 주세요. 4) 이전 사용처를 알 수 없거나 수리 후 돌려받은 장치라면 기술지원으로 접수해 주세요. 확인 후 등록을 도와 드립니다.

신호 강도가 들쭉날쭉하거나 너무 낮아요

[신호·통신이 불안정해요] 무선 성능은 안테나 방향과 설치 높이가 크게 좌우합니다. 장비 고장보다 설치 환경 영향인 경우가 훨씬 많으니 아래 순서로 조정해 보세요. 확인 순서: 1) 센서와 게이트웨이의 안테나를 모두 「수직(위 방향)」으로 세워 주세요. 센서를 눕혀 설치했다면 안테나만 꺾어 세우면 됩니다. 2) 일반형(AA)의 와이어 안테나는 구부러지거나 꺾인 곳 없이 일자로 펴 주세요. 3) 센서와 게이트웨이를 비슷한 높이에 두세요. 게이트웨이가 센서보다 낮거나 바닥에 있으면 신호가 약해집니다. 4) 너무 가까워도 신호가 왜곡됩니다. 최소 거리: 일반형(AA) 1.5~2m, 산업용 2~3m, 코인셀형 1~1.5m (센서끼리도 동일). 5) 냉장고·모터·고전압 설비·금속 벽·콘크리트 기둥 근처는 피해 주세요. 6) 그래도 낮다면 게이트웨이 위치를 센서 쪽으로 옮기거나, 중간에 게이트웨이를 하나 더 두는 구성을 검토해 주세요.

정해진 시간에 데이터가 안 들어오고 늦게 몰려 들어와요

[신호·통신이 불안정해요] 센서는 「센서 주기」마다 게이트웨이로, 게이트웨이는 「게이트웨이 주기」마다 iMonnit 으로 보냅니다. 게이트웨이 주기가 더 길면 데이터가 모였다가 한 번에 올라가 늦어 보입니다. 측정 시각은 정확히 기록됩니다. 확인 순서: 1) iMonnit 에서 센서 하트비트와 게이트웨이 하트비트를 비교해 주세요. 2) 게이트웨이 하트비트를 가장 빠른 센서보다 짧게 맞춰 주세요. 권장: 이더넷 게이트웨이 1분, IoT(LTE) 게이트웨이 5분. 3) 기준값을 넘은 경보성 데이터(Aware)는 게이트웨이 주기를 기다리지 않고 바로 올라갑니다 (On Aware Messages = Trigger Heartbeat, 기본 켜짐). 4) 게이트웨이 주기가 지났는데도 최신 데이터가 없다면, 센서를 게이트웨이 근처에 두고 실제 통신이 되는지 확인해 주세요. 5) 근처에서는 잘 된다면 설치 위치(장애물·거리)를 조정하고, 근처에서도 안 되면 센서를 초기화(Default) 후 다시 확인해 주세요.

다른 네트워크 센서 데이터가 섞여 들어오거나, 옮긴 센서가 예전 게이트웨이로 붙어요

[신호·통신이 불안정해요] 게이트웨이는 한 번 받은 센서 목록을 「Reform(재구성)」하기 전까지 그대로 기억합니다. 그래서 센서를 다른 네트워크로 옮겨도 예전 게이트웨이가 가까이 있으면 계속 받아 줄 수 있습니다. 확인 순서: 1) 센서 데이터를 CSV 로 내보내 「Gateway ID」 열에서 어느 게이트웨이를 거쳐 들어왔는지 확인해 주세요. 2) 예전 게이트웨이의 Settings → Commands → 「Reform」을 실행해 주세요 (다음 체크인 때 적용). 3) 센서를 옮긴 경우 예전·새 게이트웨이 모두 Reform 하는 것이 좋습니다. 여러 게이트웨이에서 같은 증상이면 그 센서가 거쳐 간 모든 게이트웨이를 Reform 해 주세요. 4) 웹훅으로 데이터를 받는 경우 특히 중요합니다. 게이트웨이 체크인이 웹훅을 보내므로 다른 네트워크 센서가 JSON 에 섞일 수 있습니다.

냉장·냉동고나 기계 주변에서만 자주 끊겨요 (설치 환경 영향)

[신호·통신이 불안정해요] 센서가 통신하지 못하는 가장 흔한 원인은 주변 환경입니다. 특히 냉동고 제상 히터, 모터, 피복이 없는 전선, 금속 구조물이 신호를 방해합니다. 확인 순서: 1) 끊김이 일정한 간격(3·6·12·24시간)으로 반복된다면 냉동고 제상 주기와 겹치는지 확인해 주세요. 2) 센서 본체는 냉동고 밖에 두고, 프로브(측정선)만 안으로 넣는 설치를 권장합니다. 프로브는 제상 장치에서 떨어뜨려 주세요. 3) 냉장·냉동·다습 환경에는 방수·방진 등급을 갖춘 산업용(IND) 센서를 써 주세요. 일반형·코인셀형은 결로로 내부가 젖을 수 있습니다. 4) 시험할 때는 센서를 설치 위치에서 떼어 게이트웨이와 3~4m 거리, 시야가 트인 곳에서 확인해 주세요. 5) 제상 때 잠깐 오르는 온도로 알림이 울린다면, 알림 규칙에 「지연(Delay)」을 넣어 일정 시간 지속될 때만 알리도록 바꿔 주세요.

같은 측정값이 여러 번 중복으로 들어와요

[신호·통신이 불안정해요] 센서는 게이트웨이의 수신 확인(ACK)을 못 받으면 같은 값을 최대 3번 다시 보냅니다. 중복은 보통 신호가 약하거나 주변 간섭이 있을 때 생깁니다. 확인 순서: 1) 센서를 켠 직후 30초 간격으로 여러 번 들어오는 것은 정상적인 초기 연결 과정이니 몇 분 기다려 주세요. 2) 평소에도 중복된다면 신호 강도를 확인하고 안테나 방향·설치 높이를 조정해 주세요. 3) 센서를 게이트웨이 근처로 옮겨 시험해 보고, 근처에서 정상이라면 설치 위치의 간섭 요인을 줄여 주세요.

배터리 잔량이 오르락내리락하거나 실제보다 낮게 보여요

[배터리·전원] 잔량이 조금씩 오르내리는 것은 정상 동작입니다. ALTA 센서는 무선 송신 중(가장 부하가 큰 순간)에 전압을 재기 때문에 한 번 한 번의 값보다 「긴 기간의 추세」가 더 정확합니다. 확인 순서: 1) 하루 이틀의 값보다 몇 주 단위의 그래프 추세로 판단해 주세요. 2) 하트비트를 10분 미만으로 짧게 설정했다면 소모가 크게 늘고 값도 들쭉날쭉해집니다. 필요한 만큼만 짧게 설정해 주세요. 3) 냉장·냉동고 같은 저온, 전파 간섭이 심한 곳, 게이트웨이와 멀어 신호가 약한 곳은 잔량 표시가 부정확해질 수 있습니다. 4) 정말 빨리 닳는다면 일반형(AA)은 새 배터리로 바꿔 경과를 봐 주세요. 산업용은 기술지원으로 접수해 주세요.

배터리는 얼마나 가나요?

[배터리·전원] 설치 환경과 하트비트 설정에 따라 다르지만, ALTA 일반형(AA)은 10년 이상, 산업용은 7년 이상, 코인셀형은 3년 이상 사용할 수 있습니다. 확인 순서: 1) 하트비트(보고 주기)가 짧을수록, 측정 횟수(Assessments)가 많을수록 수명이 짧아집니다. 2) 게이트웨이와 거리가 멀거나 장애물이 많아 재전송이 잦으면 소모가 늘어납니다. 3) 저온 환경에서는 배터리 성능이 떨어집니다. 냉동 환경은 리튬 배터리·산업용 센서를 권장합니다.

센서 배터리는 어떻게 교체하나요? 어떤 배터리를 써야 하나요?

[배터리·전원] 일반형은 AA 1.5V 2개, 코인셀형은 CR2032, 산업용은 3.6V 리튬(ER14505M) 전용 배터리를 씁니다. 산업용에는 일반 AA 건전지를 쓰면 전압이 부족해 동작하지 않습니다. 확인 순서: 1) 일반형(AA): 배터리 덮개를 밀어 열고 AA 2개를 극성에 맞게 넣은 뒤 닫아 주세요. 2) 코인셀형: 케이스 양옆을 눌러 분리하고 CR2032 를 (+)면이 바닥을 향하게 넣은 뒤 「딸깍」 소리가 나게 닫아 주세요. 3) 산업용: 방수 성능을 지키기 위해 직접 개봉보다는 기술지원 접수를 권장합니다. 부득이 교체할 때는 반드시 3.6V 리튬 전용 배터리를 사용해 주세요. 4) 교체 후 iMonnit 에서 잔량이 100% 가까이 표시되는지 확인해 주세요. 5) 다 쓴 배터리는 분리배출해 주세요.

산업용 센서 전원 버튼은 어떻게 쓰나요? (켜기·끄기·즉시 전송)

[배터리·전원] 산업용(IND) 센서는 방수형 전원 버튼 하나로 켜기·끄기·즉시 전송을 합니다. 확인 순서: 1) 켜기: 짧게 눌렀다 떼면 녹색 깜빡임 → 2초 후 녹색 2초 점등 → 녹색 2번 깜빡이면 게이트웨이 연결 성공입니다. 깜빡이지 않으면 연결 실패입니다. 2) 즉시 전송(켜진 상태): 짧게 누르면 현재 값을 바로 보냅니다. 녹색 2번 = 성공, 깜빡임 없음 = 실패(값은 저장해 두었다가 나중에 보냄). 3) 끄기: 3초 이상 길게 누르면 녹색 → 빨간색으로 바뀌며 꺼집니다. 4) 정상 동작 중에는 배터리 절약을 위해 LED 가 꺼져 있는 것이 정상입니다.

「HW Failure」·「Hardware Failure (Short)」 오류가 떠요

[오류 메시지가 떠요] 센서가 스스로 이상을 감지해 알려 주는 메시지입니다. 배터리가 덜 꽂혔거나, 물기·고열 영향, 배터리 이상이 흔한 원인이라 점검으로 해결되는 경우가 많습니다. 확인 순서: 1) 센서에 물기·부식·깨짐 같은 손상이 없는지 눈으로 확인해 주세요. 침수 흔적이 있다면 더 사용하지 말고 기술지원으로 접수해 주세요. 2) 일반형(AA): 배터리를 빼고 60초 기다린 뒤 끝까지 단단히 다시 끼워 주세요. 3) 그래도 뜨면 iMonnit 센서 Settings 의 「Default」로 초기화하고 새 배터리로 바꿔 주세요. 4) 산업용: 케이스는 열지 말고, 외관의 미세한 균열(고정 나사 과조임 등)만 확인한 뒤 초기화해 보세요. 계속되면 접수해 주세요. 5) 센서가 사양 온도를 넘는 곳에 있지 않은지 확인해 주세요 (일반형 알카라인 -18~55℃, 리튬 -40~85℃, 산업용 -40~85℃). 6) 젖었던 센서는 완전히 말린 뒤 초기화·배터리 교체를 해 보고, 그래도 오류가 계속되면 접수해 주세요.

「No Sensor Detected」 또는 -999.9℃ / 1767.8℉ 가 표시돼요

[오류 메시지가 떠요] 센서 본체가 측정부(프로브)에서 값을 읽지 못한다는 뜻입니다. 대부분 프로브 선의 손상이나 접속 불량, 배터리가 끝까지 꽂히지 않은 경우입니다. 확인 순서: 1) 프로브 선이 꺾이거나 눌리거나(문틈 끼임 등) 찢어진 곳이 없는지 확인해 주세요. 2) 냉장·냉동고 안에 있다면 꺼내서 선을 곧게 편 상태로 시험해 주세요. 3) 배터리를 빼고 60초 뒤, 케이스 안쪽 끝까지 밀어 넣어 다시 끼워 주세요. 4) iMonnit 센서 Settings 의 「Default」를 누르고 다음 통신 때 값이 돌아오는지 봐 주세요. 5) 새 배터리로 바꿔도 같은 값이 나오면 프로브 손상 가능성이 높으니 기술지원으로 접수해 주세요.

온도 값이 실제와 조금 달라요 (보정 방법)

[오류 메시지가 떠요] ALTA 온도 센서는 출고 상태 ±1℃, 보정 후 ±0.25℃ 수준입니다. 기준 온도계와 비교해 iMonnit 에서 보정할 수 있습니다. 확인 순서: 1) 센서와 기준 온도계를 같은 곳에 두고 온도가 안정될 때까지(약 90분) 기다려 주세요. 너무 빨리 보정하는 것이 실패의 가장 흔한 원인입니다. 2) iMonnit → 센서 → 「Calibrate」 탭 → 「Actual reading is」에 기준 온도(℃/℉ 단위 일치)를 입력하고 Calibrate 를 눌러 주세요. 3) 보정은 다음 정기 통신 때 적용되므로 그때까지 같은 환경에 두어 주세요. 4) 얼음물(얼음+물, 15분 저어 안정)에 프로브를 넣으면 약 0℃ 기준으로 보정할 수 있습니다.

전류 센서(CT) 값이 0 이거나 이상하게 나와요

[오류 메시지가 떠요] 전류 센서는 순간 전류가 아니라 보고 주기 동안의 누적(Ah)과 최대·최소·평균값을 보냅니다. CT 를 감는 방법이 가장 흔한 원인입니다. 확인 순서: 1) CT 는 활선(L) 한 가닥에만 감아 주세요. 활선과 중성선을 함께 감으면 서로 상쇄되어 0 이 나옵니다. 2) CT 를 다룰 때는 리드선이 아니라 CT 몸체를 잡아 주세요. 3) 측정 간격(Minimum Measurement Interval)은 기본 5초보다 짧게 하지 마세요. 4) Wh·kWh 로 보려면 Scale 에서 단위를 바꾸고 전압(V)을 입력해 주세요. 5) 정격보다 아주 작은 전류(정격의 10% 이하)는 정확도가 떨어집니다. 20A CT 는 약 0.1A, 150A 는 약 0.3A 이하를 읽지 못합니다.

이더넷 게이트웨이가 iMonnit 에 연결되지 않아요 (오프라인)

[게이트웨이 문제] 게이트웨이는 인터넷으로 iMonnit 서버와 통신하므로 항상 인터넷에 연결되어 있어야 합니다. 게이트웨이 LED 상태를 보면 어디가 막혔는지 빠르게 알 수 있습니다. 확인 순서: 1) 게이트웨이가 iMonnit 계정의 네트워크에 등록되어 있는지 확인해 주세요. 2) 전원을 켜면 LED 가 위에서부터 차례로 꺼지는 「워터폴」 패턴이 나와야 자체 점검 통과입니다. 3) 맨 아래 LED: 녹색 고정 = 인터넷(IP) 정상 / 빨간색 = IP 를 받지 못함 → 랜선·공유기를 확인하거나 노트북을 같은 랜선에 꽂아 인터넷이 되는지 확인해 주세요. 4) 가운데 LED: 빨간색 = 서버 연결이 막힘 → 사내 방화벽에서 「외부로 나가는 TCP 3000번 포트」와 sensorsgateway.com 접속(DNS)을 허용해 달라고 전산 담당자께 요청해 주세요. 5) LED 3개가 모두 녹색이면 정상 체크인 중입니다. 6) 그래도 안 되면 마지막 방법으로 Utility 버튼을 약 15초간 눌러 LED 가 빨간색으로 깜빡이면 떼 주세요 (공장 초기화: DHCP 자동 IP, 기본 서버 iMonnit 으로 복귀).

이더넷 게이트웨이 LED 상태가 무슨 뜻인가요?

[게이트웨이 문제] 이더넷 게이트웨이는 LED 3개가 각각 녹색·빨간색으로 상태를 알려 줍니다. 위에서부터 센서 네트워크 · 서버 · 인터넷(LAN) 상태입니다. 확인 순서: 1) 켜짐 단계: 빨강/녹색 깜빡임 후 1초간 녹색, 이어 위에서부터 차례로 꺼짐(워터폴) = 자체 점검 통과. 실패하면 10초 뒤 같은 패턴을 반복합니다. 2) 접속 단계: 1.5초 녹색 점등으로 부팅 완료 → 맨 위 LED 녹색과 함께 서버·센서 연결을 시도합니다. 3) 정상: LED 3개 모두 녹색. 4) 맨 아래 빨간색 = 인터넷(IP) 없음 / 가운데 빨간색 = 서버 연결 막힘(포트 3000·DNS) / 특정 LED 깜빡임·빨간색 = 해당 영역 문제. 5) 2분이 지나도 부팅이 끝나지 않으면 LED 사진을 찍어 기술지원으로 접수해 주세요.

사내 방화벽·네트워크에서 무엇을 열어 줘야 하나요? (전산팀 전달용)

[게이트웨이 문제] 게이트웨이는 밖으로 나가는 연결만 사용하므로 들어오는(인바운드) 규칙은 필요 없습니다. 아래 내용을 그대로 전산 담당자께 전달해 주세요. 확인 순서: 1) 이더넷 게이트웨이: 외부로 나가는(아웃바운드) TCP 3000번 포트 허용. 2) LTE·셀룰러 게이트웨이: UDP 3000번 포트 사용 (통신사 망 이용). 3) DNS: sensorsgateway.com 조회가 되어야 합니다 (기종에 따라 t1/t2/u1/u2.sensorsgateway.com). 4) 고정 IP 허용 목록이 필요한 경우: 게이트웨이 서버 166.117.35.68, 166.117.206.175 (2026-03-17 부 변경). 5) 사용자 PC·휴대폰에서 iMonnit 접속: TCP 80/443. 6) 웹훅을 받는 서버가 있다면 발신 IP 64.78.195.12, 66.114.115.20 을 허용해 주세요.

게이트웨이에 고정 IP 를 넣고 싶어요 (로컬 설정 페이지 포함)

[게이트웨이 문제] 이더넷 게이트웨이는 기본이 DHCP(자동 IP)입니다. 이미 온라인이면 iMonnit 에서, 오프라인이면 게이트웨이 로컬 설정 페이지에서 고정 IP 를 넣을 수 있습니다. 확인 순서: 1) 온라인일 때: iMonnit → Gateways → 해당 게이트웨이 → Settings → Networks → DHCP 를 Static 으로 바꾸고 IP·서브넷 마스크·기본 게이트웨이·DNS 4개를 「모두」 입력 후 Save. 2) 로컬 설정 페이지 열기: 전원을 끈 상태에서 Utility 버튼을 누른 채 전원을 켜고, LED 3개가 빨간색 고정(약 5초)이 되면 바로 떼 주세요. 2분간 같은 망에서 게이트웨이 IP 로 접속할 수 있습니다. 3) DHCP 가 없는 망: 부팅 후 2분간 IP 를 못 받으면 AutoIP(169.254.100.1)로 바뀝니다. PC 를 랜선으로 직접 연결해 접속할 수 있습니다. 4) 로컬 페이지 Settings → Ethernet LAN 탭에서 같은 4개 항목을 입력하고 저장합니다.

LTE(셀룰러)·IoT 게이트웨이가 연결되지 않아요

[게이트웨이 문제] LTE 게이트웨이는 통신사 망으로 연결됩니다. 처음 개통 연결은 20분 이상 걸릴 수 있어, 처음이라면 조금 기다려 보시는 것이 먼저입니다. 확인 순서: 1) 처음 설치라면 맨 아래 LED 가 1초에 한 번 녹색으로 깜빡이는 동안(개통 중) 20분 정도 기다려 주세요. 2) 맨 아래(셀룰러) LED: 녹색 고정 = 연결됨 / 2번씩 깜빡 = 기지국 찾는 중 / 3번씩 깜빡 = 망 연결 안 됨 / 녹색·빨강 번갈아 = 신호 약함 / 빨강 깜빡 = 연결 오류. 3) 신호가 약하면 창가나 실외에 가까운 곳으로 옮겨 주세요. 지하·철골 구조물 안쪽은 신호가 약합니다. 4) 전원을 끄고 유심이 단단히 꽂혀 있는지 확인한 뒤 다시 켜 주세요. 5) Utility 버튼을 15~20초 눌러 LED 가 빨간색으로 깜빡이면 떼 주세요 (재접속). 6) 가운데 LED 빨간색(서버 통신 실패)인데 아래 LED 가 녹색이면, 위 5번 재접속을 한 번 더 해 주세요.

셀룰러 게이트웨이 LED 가 꺼져 있어요

[게이트웨이 문제] 셀룰러 게이트웨이를 배터리로 쓰거나 「Force Low Power」 모드라면 LED 가 꺼져 있는 것이 정상입니다. iMonnit 의 마지막 체크인 시각으로 동작을 확인해 주세요. 확인 순서: 1) iMonnit 에서 게이트웨이의 최근 체크인 시각이 정상인지 확인해 주세요. 2) Gateways → 해당 게이트웨이 → Settings → General → 「Gateway Power Mode」에서 모드를 확인할 수 있습니다. (Standard: 상시 전원이면 LED 켜짐, 배터리면 꺼짐) 3) 체크인도 멈춰 있다면 전원 공급(어댑터·배터리)을 확인하고 「LTE 게이트웨이 연결 안 됨」 문서를 따라 주세요.

게이트웨이 「Reform(재구성)」은 언제, 어떻게 하나요?

[게이트웨이 문제] Reform 은 게이트웨이가 기억하는 센서 목록을 비우고 iMonnit 에서 새로 받게 하는 명령입니다. 센서를 다른 네트워크·게이트웨이로 옮긴 뒤에 꼭 필요합니다. 확인 순서: 1) iMonnit → Gateways → 해당 게이트웨이 → Settings → Commands → 「Reform」 버튼. 2) 다음 게이트웨이 체크인 때 실행되며, 기록(History)에 Gateway Management 메시지(4 → 2)가 남습니다. 3) 센서를 옮겼다면 예전 게이트웨이와 새 게이트웨이를 모두 Reform 해 주세요. 4) Reform 후 센서가 바로 안 붙으면 센서 전원을 껐다 켜 주세요.

게이트웨이 기록의 「Gateway Management」 메시지는 무슨 뜻인가요?

[게이트웨이 문제] 게이트웨이가 체크인할 때 한 일을 기록한 것입니다. 기록 위에 마우스를 올리면 번호가 보입니다. 확인 순서: 1) 0 = 센서 데이터 전송 / 1 = 센서로 설정 전달 / 2 = 센서 목록 갱신 / 3 = 네트워크 설정 변경. 2) 4 = Reform 명령 수신 / 5 = 공장 초기화 / 11 = 게이트웨이 시작(전원 켜짐 등) / 250 = 펌웨어 업데이트 중. 3) 자주 보이는 조합: 「11, 2」 = 전원 재시작 / 「4, 2」 = Reform / 「11, 8, 2」 = 버튼으로 공장 초기화. 4) Messages 열의 숫자는 그 체크인에 올라간 센서 메시지 수입니다. 연결이 복구된 직후에는 크게 나올 수 있습니다.

게이트웨이 자동 리셋(재부팅) 설정은 어떻게 하나요?

[게이트웨이 문제] 게이트웨이는 네트워크 문제로 끊겼을 때 스스로 다시 접속할 수 있도록 정해진 시간마다 재부팅합니다. 기본값은 168시간(1주일)입니다. 확인 순서: 1) 관리자(Admin) 권한 계정으로 iMonnit 에 로그인합니다. 2) Gateways → 해당 게이트웨이 → Settings → Commands 탭. 3) 「Auto Reset (Hours)」에 시간 단위로 입력하고 Save. 다음 체크인부터 적용됩니다. 4) 끄려면 0 을 입력해 주세요.

게이트웨이·센서 펌웨어 업데이트는 어떻게 하나요?

[게이트웨이 문제] 게이트웨이가 iMonnit 에 정상 체크인 중일 때 원격으로 업데이트할 수 있습니다. 보통 10분 안에 끝납니다. 확인 순서: 1) 관리자 계정으로 로그인 → Gateways 에서 업데이트 가능한 게이트웨이에 다운로드 아이콘이 보입니다. 2) 선택 후 「Update Selected」(또는 Settings → Commands → Update). 다음 체크인 때 진행됩니다. 3) 센서 무선 업데이트는 신호 80% 이상·배터리 60% 이상일 때만 진행하고, 게이트웨이를 먼저 업데이트해 주세요. 4) 센서 업데이트가 실패해도 보통 24시간 안에 다시 연결됩니다. 최소 4시간은 기다린 뒤 전원을 껐다 켜 주세요.

인터넷이 끊기면 데이터가 사라지나요?

[게이트웨이 문제] 아닙니다. 연결이 끊긴 동안 센서는 측정값을 수천 건까지, 게이트웨이는 최대 5만 건까지 저장했다가 연결이 복구되면 순서대로 보냅니다. 확인 순서: 1) 복구 직후에는 최신 값이 먼저, 이어서 밀린 데이터가 여러 번에 나눠 올라옵니다(몇 시간 걸릴 수 있음). 2) 밀린 데이터에도 알림 규칙이 적용됩니다. 지난 시각의 알림이 뒤늦게 올 수 있습니다. 3) 센서 저장 공간이 가득 차면 그 이후는 기록되지 않으니, 장시간 끊김이 예상되면 미리 접수해 주세요.

센서가 많을 때 게이트웨이 1대에 몇 개까지 붙이나요?

[게이트웨이 문제] 네트워크 하나에 센서 100개 이하를 권장하며, 게이트웨이 1대가 처리하는 메시지는 초당 1건 정도를 기준으로 설계합니다. 확인 순서: 1) 많은 센서가 동시에 이벤트를 보내는 현장(모션 센서 다수 등)은 네트워크를 나눠 게이트웨이를 분산해 주세요. 2) 센서는 같은 네트워크의 게이트웨이에만 붙으므로, iMonnit 네트워크를 구역별로 나누면 부하를 고르게 할 수 있습니다. 3) 현장 규모에 맞는 구성은 기술지원·영업 상담으로 함께 설계해 드립니다.

알림(문자·이메일·푸시)이 오지 않아요

[알림이 안 와요] 알림은 「네트워크 알림 켜짐 → 규칙 조건 → 받는 사람 → 발송 수단」 중 한 곳만 막혀도 오지 않습니다. 위에서부터 차례로 확인하면 대부분 원인을 찾을 수 있습니다. 확인 순서: 1) Networks → 해당 네트워크에서 「Notifications Enabled」가 체크되어 있는지 확인해 주세요. 2) Rules 에서 해당 규칙이 일시정지·비활성 상태가 아닌지, 센서가 조건에 연결되어 있는지 확인해 주세요. 3) 기준값과 단위(℃/℉), 측정 항목(예: 온습도 센서의 습도/온도)이 맞는지 확인해 주세요. 4) 규칙의 받는 사람(To)에 본인이 들어 있는지, 사용자 정보의 이메일·휴대폰 번호가 정확한지 확인해 주세요. 5) 「지연(Delay)」이나 「일정(Schedule)」이 걸려 있으면 조건이 그 시간 동안 이어지거나 정해진 시간대일 때만 발송됩니다. 6) 문자·음성·푸시는 iMonnit Premiere 와 알림 크레딧이 필요합니다. 이메일은 스팸함과 회사 메일 차단(imonnit.com 허용)을 확인해 주세요. 7) 데이터를 내보내 해당 시각 값의 「Alert Sent」가 True 인지 보면 발송 여부를 확인할 수 있습니다.

알림 규칙(Rule)은 어떻게 만드나요?

[알림이 안 와요] 규칙은 「조건(센서 값) + 할 일(알림 발송)」으로 이루어집니다. 가장 많이 쓰는 것은 센서 값 기준, 통신 끊김(Inactivity), 배터리 잔량 알림입니다. 확인 순서: 1) 왼쪽 메뉴 Rules → 「+ Create New Rule」. 2) 규칙 종류 선택: Sensor Reading(값 기준) / Device Inactivity(통신 끊김) / Battery Level(배터리) / Scheduled / Advanced. 3) 센서를 고르고 조건(예: 온도 8℃ 초과)을 입력 → Save. 4) Task 에서 Send Email · Send Text · 음성 · 푸시 중 선택하고 받는 사람을 지정합니다. 5) 규칙 이름을 정하고 저장하면 끝입니다. 필요하면 일정(Schedule)과 지연(Delay)을 추가해 주세요.

잠깐 문을 열 때마다 알림이 와요 / 담당자별로 순차 알림을 받고 싶어요

[알림이 안 와요] 알림 「지연(Delay)」을 쓰면 조건이 일정 시간 계속될 때만 알림이 갑니다. 같은 기능으로 1차 담당자 → 일정 시간 뒤 2차 관리자 순서의 단계별 알림도 만들 수 있습니다. 확인 순서: 1) Rules → 해당 규칙 → Tasks 탭. 2) 발송 수단을 선택하고 받는 사람(To) 옆 「+」 → 사용자 선택 → 지연 시간 선택 → Set. 3) 지연 시간 안에 값이 정상으로 돌아오면 알림 없이 자동 해제됩니다. 4) 사용자마다 다른 지연을 주면 단계별(에스컬레이션) 알림이 됩니다. 예: 1차 즉시, 2차 15분 뒤.

「통신 끊김(Inactivity)」 알림이 너무 자주·잘못 와요

[알림이 안 와요] 통신 끊김 판정 시간이 너무 짧으면 정상인데도 알림이 옵니다. 「센서 하트비트×2 + 게이트웨이 하트비트 + 1분」 이상으로 맞춰 주세요. 확인 순서: 1) 예) 센서 60분·게이트웨이 5분이면 끊김 시간을 126분 이상으로 설정합니다. 2) 알림을 받으면 iMonnit 에서 해당 장치가 지금도 오프라인인지 먼저 확인해 주세요. 3) 센서 하나만 오프라인 → 마지막 체크인·신호·배터리 확인 / 모든 센서 오프라인 → 게이트웨이 전원·인터넷 확인. 4) 「Back Online」 규칙도 같은 시간으로 맞추면 복구 알림까지 받을 수 있습니다.

문자(SMS) 알림은 어떻게 받나요? 예전 방식 문자가 안 와요

[알림이 안 와요] 예전의 무료 이메일-문자 변환 방식은 대부분 통신사에서 더 이상 지원하지 않습니다. 지금은 「Direct Delivery SMS」(알림 크레딧 사용) 또는 앱 푸시 알림을 이용해 주세요. 확인 순서: 1) 사용자 정보에 휴대폰 번호가 정확히 입력되어 있는지 확인합니다. 2) 알림 크레딧 잔여량을 확인합니다 (문자·음성은 크레딧이 차감됩니다). 3) 비용 없이 즉시 받고 싶다면 iMonnit 웹앱을 설치해 푸시 알림을 켜 주세요. 4) 크레딧 충전·구독 관련은 기술지원 접수로 문의해 주세요.

휴대폰 앱 설치와 푸시 알림은 어떻게 하나요?

[알림이 안 와요] iMonnit 앱은 이제 앱스토어가 아니라 웹앱(PWA)으로 설치합니다. iMonnit 로그인 화면 하단의 「Install App」 또는 imonnit.com/Setup/InstallApp 에서 설치할 수 있습니다. 확인 순서: 1) 아이폰: 반드시 Safari 로 설치 링크를 열고 → 공유 → 「홈 화면에 추가」. 2) 안드로이드: Chrome 으로 링크를 열고 「설치」. 3) 푸시 켜기: Users → 내 계정 → Notification 탭 → 「Allow Push Messages」를 켜고 휴대폰 권한 요청을 허용합니다. 4) 규칙의 Tasks → Edit Alert 에서 Push 열의 종 아이콘이 녹색이 되게 켜 주세요.

알림 이메일이 스팸함으로 가거나 반송돼요

[알림이 안 와요] 회사 메일 서버나 스팸 필터가 iMonnit 메일을 막는 경우가 가장 흔합니다. 확인 순서: 1) 사용자 정보의 이메일 주소에 오타나 앞뒤 공백이 없는지 확인해 주세요. 2) 스팸함을 확인하고, 전산 담당자께 「imonnit.com 도메인 수신 허용」을 요청해 주세요. 3) 메일함 용량이 가득 차 있지 않은지 확인해 주세요.

iMonnit 계정과 사용자는 어떻게 구성되나요? (계정 계층 구조)

[iMonnit 계정·설정] iMonnit 에서 「계정」은 한 사람이 아니라 하나의 지점·건물처럼 동작하고, 그 안에 여러 「사용자」가 권한별로 소속됩니다. 구독도 사용자가 아니라 계정 단위로 적용됩니다. 확인 순서: 1) 계정: 지점·건물 단위의 관리 단위로, 구독과 기기 설정이 계정별로 관리됩니다. 2) 사용자: 한 계정 안에 여러 명을 개별 ID 로 등록하고 관리자/일반 사용자 권한을 줄 수 있습니다. 처음 계정을 만든 사람이 최상위 관리자입니다. 3) 계층: 최상위 관리자 계정 → 상위 구역 계정 → 하위 구역 계정. 상위 관리자는 하위 계정을 관리할 수 있지만, 하위 사용자는 상위 정보에 접근할 수 없습니다. 4) 한 계정 안에서 네트워크를 최대 5개까지 나눠 센서·게이트웨이를 구역별로 관리할 수 있습니다.

iMonnit 계정은 어떻게 만드나요?

[iMonnit 계정·설정] www.imonnit.com 에서 Create Account 로 만들 수 있습니다. 구독 코드를 받으셨다면 가입 때 입력하고, 없으면 체험 기간이 자동으로 시작됩니다. 확인 순서: 1) www.imonnit.com → 「Create Account」. 2) 주 관리자(대표 담당자) 정보를 입력합니다. 3) 받으신 Premiere 구독 코드가 있으면 입력합니다 (비워 두면 체험판). 4) 약관 동의 후 기본 네트워크가 만들어지면 게이트웨이 → 센서 순서로 장치를 등록합니다.

iMonnit 에 센서·게이트웨이는 어떻게 등록하나요?

[iMonnit 계정·설정] 장치 라벨의 ID 와 보안코드(SC)를 입력하거나 휴대폰으로 QR 코드를 찍어 등록합니다. 확인 순서: 1) Sensors(또는 Gateways) → 「Add Sensor/Add Device」. 2) 장치 ID 와 보안코드(SC)를 입력합니다. SC 는 영문 대문자만 사용합니다. 3) 용도 프리셋(보고 주기 등)을 고르거나 직접 설정 후 Save. 4) 게이트웨이 온라인 → 센서 전원 켜기 → 게이트웨이 Utility 버튼 짧게 누르기 순서로 연결을 확인합니다. 5) 마지막에 배터리 부족·통신 끊김 알림 규칙을 함께 만들어 두면 좋습니다.

계정에 사용자를 추가하고 권한을 주고 싶어요

[iMonnit 계정·설정] 여러 사용자는 iMonnit Premiere 에서 가능합니다. 관리자 권한 계정으로 Users 메뉴에서 추가하고 권한을 세부 설정할 수 있습니다. 확인 순서: 1) 관리자 계정으로 로그인 → 왼쪽 Users → 새 사용자 정보 입력 → Submit. 2) 권한: Users → 사용자 선택 → 자물쇠 아이콘 → 항목별 권한 설정 → Save. 3) 「Networks」 항목에서 그 사용자가 볼 수 있는 네트워크만 체크하면 구역별 담당자를 나눌 수 있습니다.

네트워크를 추가하고 싶어요 (구역별로 나누기)

[iMonnit 계정·설정] 네트워크는 게이트웨이와 센서를 묶어 서로 통신을 허용하는 단위입니다. 장치는 한 번에 한 네트워크에만 속합니다. 확인 순서: 1) 왼쪽 Networks → 「+ New Network」 → 이름 입력 → Save. 2) 이어서 그 네트워크에 게이트웨이와 센서를 등록합니다. 3) 한 계정(지점)당 네트워크는 최대 5개까지 만들 수 있습니다.

센서를 다른 네트워크로 옮기고 싶어요

[iMonnit 계정·설정] 센서를 지우고 다시 등록할 필요 없이 「Move」로 옮길 수 있습니다. 옮긴 뒤 양쪽 게이트웨이 Reform 을 꼭 해 주세요. 확인 순서: 1) Sensors 화면에서 센서 카드의 「⋮」 → Move. 2) 오른쪽 위에서 옮길 네트워크 선택 → 장치 ID·보안코드 확인. 3) 예전 네트워크와 새 네트워크의 게이트웨이를 모두 Reform 합니다. 4) 다음 정기 통신부터 새 네트워크로 데이터가 들어옵니다.

센서 설정(보고 주기·기준값 등)은 어디서 바꾸나요?

[iMonnit 계정·설정] Sensors → 센서 선택 → Settings 탭에서 바꿀 수 있고, 변경 내용은 센서의 다음 정기 통신 때 적용됩니다. 확인 순서: 1) Heartbeat Interval: 평상시 보고 주기(기본 120분). 짧을수록 배터리 소모가 커집니다. 2) Aware State Threshold: 이 값을 넘으면 즉시 보고하고 「Aware 주기」로 더 자주 보고합니다. 3) Assessments per Heartbeat: 보고 사이에 몇 번 측정해 볼지(기준 초과 시 바로 보고). 4) Failed Transmissions Before Link Mode: 연결 실패 몇 번 뒤 다른 게이트웨이를 찾을지(0 = 찾지 않음).

하트비트·Aware·Assessment 가 무슨 뜻인가요?

[iMonnit 계정·설정] 하트비트는 센서의 정기 보고, Aware 는 기준을 넘은 「주의 상태」, Assessment 는 보고 사이의 중간 측정입니다. 확인 순서: 1) 하트비트: 정해진 주기마다 측정값·배터리·신호를 보냅니다. 물감지·도어 같은 이벤트 센서도 「살아 있음」 확인용으로 보냅니다. 2) Aware: 기준값을 넘으면 즉시 보내고, 정상으로 돌아올 때까지 더 짧은 주기로 보고합니다. 3) Assessment: 하트비트 사이에 몰래 측정해 보고, 기준을 넘을 때만 보냅니다(넘지 않은 값은 저장하지 않음). 4) Rearm(이벤트 센서): 한 번 감지 후 다음 감지까지 최소 대기 시간입니다.

고급 설정이 사라졌어요 / 다른 사용자가 로그인이 안 돼요 (구독 만료)

[iMonnit 계정·설정] iMonnit Premiere 구독이 만료되면 무료(Basic)로 바뀌어 고급 설정이 숨겨지고, 주 관리자 외 사용자는 로그인할 수 없으며, 보고 주기가 120분으로 돌아갑니다. 확인 순서: 1) Basic: 사용자 1명·최소 주기 120분·기록 90일 / Premiere: 여러 사용자·최소 주기 10분·고급 설정·기록 1년. 2) 구독 코드를 받으셨다면: 관리자 로그인 → 왼쪽 아래 Settings → Premiere → 「Subscription Key」 입력 → Submit. 3) 연장하면 사용자·10분 주기·고급 설정이 다시 살아납니다. 4) 구독 코드 발급·연장 문의는 기술지원 접수로 남겨 주세요.

아이디·비밀번호를 잊었어요 / 로그인이 잠겼어요

[iMonnit 계정·설정] iMonnit 로그인 화면의 「Forgot?」으로 재설정할 수 있습니다. 모넷코리아 홈페이지 계정과는 별개입니다. 확인 순서: 1) imonnit.com 로그인 화면 → 「Forgot?」 → 사용자 정보에 등록된 이메일 입력 → Send Email. 2) 메일로 받은 「Credential Recovery Authorization Key」를 붙여 넣고 → Set Password → 아이디 확인 후 새 비밀번호 입력. 3) 7번 틀리면 5분, 이후 10번 더 틀리면 65분간 잠깁니다. 시간이 지나면 다시 시도해 주세요. 4) 2단계 인증(OTP 앱): 로그인 → 오른쪽 위 사용자 아이콘 → Two-Factor Authentication → Enable TOTP.

센서 데이터를 엑셀(CSV)로 내려받고 싶어요 / 보고서

[데이터·보고서·연동] 센서 화면에서 바로 내려받거나(최대 5,000건), Reports 에서 기간별·정기 보고서를 만들 수 있습니다. 확인 순서: 1) 바로 받기: Sensors → 센서 선택 → 기간 지정 → Export(CSV/PDF), 최대 5,000건. 2) 기간 지정 보고서: Reports → 「Sensor Export: By Date Range」 — 최근 1년 이내, 센서 1개당 최대 7만 건(1시간 내 생성). 3) 정기 보고서: 일·주·월 단위로 예약해 자동 생성할 수 있습니다. 생성된 보고서는 30일간 보관되니 내려받아 두세요. 4) CSV 에는 측정 시각·값·배터리·신호·Gateway ID·Alert Sent 등이 들어 있습니다.
